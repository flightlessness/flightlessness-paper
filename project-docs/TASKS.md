# 项目任务

状态使用「待决定」「待办」「进行中」「已完成」。P0 优先处理影响文章公开范围或明确失效的链接，P1 处理构建与主要阅读体验，P2 处理后续维护。优先级基于 2026-11-26 的仓库审计。表中待办项为本轮建立台账时记录的计划。

| 优先级 | 任务 | 状态 | 下一步与验收 |
| --- | --- | --- | --- |
| P0 | 确认「隐藏」文章的可见范围 | 待决定 | 由作者决定保留直链、减少公开入口或停止公开，并明确 RSS 是否允许标题与摘要、公开源码是否符合目标。 |
| P0 | 修复隐藏文章的入口与输出 | 待办 | 依赖上项。按决定验证首页、Posts、分类与标签、前后篇、RSS、sitemap 和详情页。当前审计发现 5 篇详情页返回 404，同时 RSS 仍含摘录。 |
| P1 | 使 Paper 模块依赖可复现 | 待办 | 验证固定版本与校验文件的方案。在干净副本及 CI 中确认相同的依赖和成功的生产构建。 |
| P1 | 修复分类与标签卡片样式 | 待办 | 处理模板使用但发布 CSS 缺少的样式。验证窄屏、宽屏、浅色和深色，检查生成的选择器。 |
| P1 | 验证并改善页头导航 | 待办 | 验证深色切换和移动菜单可用键盘操作，检查嵌套页面的图标请求，以及导航保留 Pages 子路径。 |
| P2 | 迁移废弃语言配置并核对本地化 | 待办 | 核对 `locale`、内容语言的配置和渲染效果。验收含页面语言、日期、分页文案及分享元数据。 |
| P2 | 核实静态图标与测试文章的保留价值 | 待办 | 检查 SVG 的外部引用和测试文章的历史价值，分别记录保留或清理决定。 |
| P2 | 核查 Actions 与构建日志提示 | 待办 | 下次维护部署流程时处理 Node 运行时、模块缓存及 Git 历史深度提示。检查 Pages 构建和发布结果。 |
