# flightlessness-paper

A personal blog powered by [Hugo](https://gohugo.io/) and [Paper](https://github.com/nanxiaobei/hugo-paper).

## Writing

Create a Markdown file under `content/posts/`, add its front matter, and commit it to `main`. GitHub Actions builds and deploys the site automatically.

## Local preview

```bash
hugo server
```

The theme is managed as a Hugo Module.
